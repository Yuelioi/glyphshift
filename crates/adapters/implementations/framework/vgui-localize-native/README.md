# VGUI 本地化查询（实验）

`windows.vgui.localize-query` 在 Windows MSVC x86 目标中拦截完整本地化查询，使用既有 Native Runtime Host 的字典决策。默认 Runtime Bundle 包含其 x86 工件，App 中以“VGUI 本地化查询（实验）”提供选择；仅限以下窄能力，不代表整个游戏已支持。

## 接口边界

从已加载的 `vgui2.dll` 的公开 `CreateInterface` 获取 `VGUI_Localize005` 对象。接口名称仅用于取得候选对象，不作为 ABI 认证。识别器对函数做有界符号执行，要求：名称查询将原参数和同一 `this` 传给虚拟索引查询；无效索引返回空；成功路径与按索引取值的方法计算相同的 UTF-16 池地址；相关方法所有可达返回均符合 x86 单参数栈清理。

槽位、对象字段偏移、记录步长由当前函数的数据流推导。代码没有目标软件地址、方法字节前缀、固定查询槽位或菜单词句。未知指令形态、冲突候选、地址不属于已持有模块、非可写对象或检查期间发生变化均拒绝安装。此窄识别器不承诺所有 Source 分支或所有 `Localize005` 实现。

仅替换该对象的 vptr，影子表保留原始 RTTI 项及其他方法；不编辑原共享虚表或本地化文字表。停用关闭 Host 调用入口并等待已进入的回调完成。影子表、原函数模块和 Adapter 模块保留到进程结束，使已取得旧入口的线程仍能安全转交原函数。

## 决策与返回值

完整原文经稳定的 `NativeRuntimeHostV1.decide_utf16` 进入既有 Core/字典及诊断流程，不新增公共 ABI。内层重入查询保持原值，外层最多进行一次决策；保留原调用的 LastError。只有得到授权的替换决策、有效代次及非格式化短标签才发布指针。最多 256 个 UTF-16 单位的单行标签可替换；较长或含格式占位符/控制字符的原文可观察，替换保留原值。字体、排版和格式化入口未接入。

查询返回值拦截与已验证的标准 Label 更新共用字典。描述符为 `RetainedObject`，因为适配器会持有仍存活控件的原文和最后应用值，并在停用时恢复自己拥有的修改。译文从不代替原始本地化表内容。

返回池按“完整原文、译文”复用已验证缓冲，最多保留 4096 项，数据区总上限 1 MiB；首次需要替换时提交数据区。预算属于进程内的 Adapter 实例，换代和再次启用不重置。到达任一上限后新值保留原文，已存在的值仍可复用。旧数据不覆写、不提前回收，目标退出时由系统回收；这避免按会话无限追加数据页。

原接口返回可写指针。每次复用前，通过操作系统复制检查该缓冲；发现改写或不可读时永久停止本实例的替换。该检查不覆盖尚未再次使用的旧缓冲，也不承诺任意并发写者、越界写者或主动释放返回地址的调用者兼容。

## 控件恢复

通过公开工厂取得候选 Panel / IVGui 接口，再从实际函数识别面板调度入口、VPanel 简单 getter 和包含索引/序号/空闲项检查的寿命句柄。标准 Label 基类 RTTI、TextImage RTTI、成员 getter、宽字符 getter/setter 的配对形态均符合时，才允许调用目标自身的 Label SetText。字段及槽位由函数推导，不包含目标软件的固定配置。

`request_refresh` 只推进更新代次；真实更新在同一个目标 UI 线程执行。保留 TextImage 原本地化索引，以原始查询取得原文；不能通过译文反向猜测来源。目标 setter 自行分配/复制缓冲并更新布局、重绘，适配器不直接修改 TextImage 字段。最多跟踪 4096 个控件和 256 种布局；未知形态保留原有查询能力。

停用先关闭 Host 调用，随后等待 UI 线程恢复包括隐藏控件在内的已跟踪对象。句柄序号改变、对象/成员改变或游戏自行改字时放弃旧归属，不能写回陈旧快照。没有 UI 回调时有界等待失败，不能报已恢复；驻留回调保留待恢复工作，完成前不能再次启用。恢复队列及控件写入不依赖 Frida。

自动刷新限于上述已验证的标准本地化短标签。非标准控件、非本地化文字、格式化文本、超长文本和不同 UI 线程的控件仍不承诺覆盖；接口或编译形态不符合时，已有副本仍需要目标正常重建。

## 验证

运行 `scripts/test-vgui-localize.ps1` 编译独立 C++ 查询宿主和此 Adapter，并通过生产 Native Host / Runtime 合同验证两种槽位/对象布局、错误方法表达式/ABI 拒绝、两代字典、保留指针、原表、另一实例、格式化透传、写入拒绝、两个容量上限、重入、错误输出、代次和在途回调停用。合成输入和代码可提交，构建产物及日志留在本地测试目录。

此前一个设置标签已通过原生 Runtime 字典首代、次代及停用后重建恢复。本轮新增原生 DLL 在同一个主菜单按钮上完成两代译文和停用恢复，三阶段画面及像素断言通过，无需关闭菜单或重启游戏；另有合成对象合同覆盖旧代次、外部改字、寿命复用、隐藏恢复及停用超时。该结果限定已验证的目标接口及可重建标签，不代表主菜单、任意 Source 软件或所有查询消费者均已支持。详细状态见 [原生接入工作页](../../../../../flightdeck/work/adapter-coverage-and-x86/slices/vgui-localize-native.md)。

离线工具 `cargo run -p glyphshift-adapter-vgui-localize-native --example query_shape -- <methods-file>` 接受长度前缀的函数字节集合，仅运行同一识别器，不加载或执行被检查的模块。它不证明对象来源、实时安装成功或可见文字变化。
