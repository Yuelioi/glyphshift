# CatSystem2 文字对象（实验）

`windows.catsystem2.utf8-text` 提供 `TextObserve`、`TextReplace`，仅发布 Windows x86 工件。定位为 `RetainedObject`，组件及 detour 保留到目标退出。它按 CatSystem2 引擎结构识别，不包含游戏名、样本地址、台词或机器配置。

## 识别与调用边界

当前支持 MSVC x86 的 `kcFEScriptObjStringUTF8` 窄形态。识别器关联 RTTI、四项虚表、`str` / `apend` 命令表、栈上字符串参数、复制循环、缓冲 getter 和销毁函数，以及 `apendmark` / `skip` 命令与显示方法；从这些关系推导函数地址及缓冲成员位置。仅一个候选成立才激活，歧义、错误类型、错误成员、错误显示方法和不支持的代码形态拒绝。另支持 `kcFEScriptObjString` 经典窄形态：三项虚表、EDI/ESI setter、EBX append、EDI 销毁及 EAX/ECX 显示方法。字段由销毁、复制、显示和 skip 命令交叉验证；调用桥保留非易失寄存器及栈清理。经典分支不包含历史容器刷新支持；不支持其他 ABI、混合对象分支或 x64。

对象回调提供首次附加时已经缓存的完整正文。显示入口同时接收历史页直接提交的无标记正文；识别到 `kcFEScriptObjLogStringUTF8` 后，利用其容器回调更新已显示的文字对象，不依赖历史行运行普通正文回调。连接时已经打开的历史页尚不枚举旧行，需要重新打开历史页使其经过显示入口。每次外部修改后及字典换代时重新决策；未变化的活动对象每秒补充一次观测。决定由现有 Native Host/Core/字典链路产生，未修改公共 ABI。次数反映观测调用，不表示画面刷新成功；保留周期观测以支持暂停后恢复采集。

目标自身 setter 分配并复制当前分支的编码输入，适配器不写入引擎字符串缓冲，不把借用指针留给目标。替换前保存原文和最后应用值；字典删除、非法输出或超出长度时使用原文。外部 setter 会终止旧记录；外部 append 在目标线程恢复原文后执行，避免把译文当成下一次追加的原文。销毁入口清除对象记录，复用相同地址不会继承旧台词。

经典 ANSI 分支使用目标 `GetACP` 返回的代码页，当前允许 932/936/949/950/1250–1258。双向严格转换和往返检查拒绝非法字节、默认字符及 best-fit 替代；不猜测第三方补丁自定义代码页。已验证实机为系统 ANSI 中文分支，其他代码页仅有合成转换证据。解析并保留开头的 `\cd0x########;` / `\c0x########;` 颜色命令及末尾单字节 `FF` 标记，Host 只接收正文；未知或内嵌控制命令仍不替换。逻辑 ID 保持不变以兼容已有探针配置。

## 更新、恢复和资源

控制线程只发布更新请求，修改由引擎对象回调在所属线程完成。显示入口已确认的无标记正文也使用同一显示与恢复路径。带有末尾 `FF FF` 标记（可重复）的正文将文字和标记分开处理，Host 仅接收 UTF-8 正文，替换和恢复保留完整标记。引擎 setter 后调用已识别的显示及完成当前文字方法，重建当前句显示；这会一次显示当前句，不推进剧情。显式刷新会重试已替换的已显示正文或带标记正文，即使译文未变化；每秒观测不会重复重建显示。停用后等待该线程恢复包含隐藏对象的已修改记录；无回调时三秒超时并返回失败，保留待恢复状态。后续回调可完成恢复。停用不卸载 detour，未激活时不调用 Host。

对象原文或类型被外部改变时放弃旧记录，避免覆盖游戏的新内容。当前仅验证同一游戏线程管理文字的模型，不承诺任意并发写入支持。

单条原文和译文各最多 8192 个编码后字节，同时最多记录 256 个对象，原文与译文有效载荷预算最多 4 MiB。满额时新对象透传，已替换对象的恢复记录继续保留。字符串读取有边界，剥离已识别的末尾标记后验证 UTF-8；源文可观测，但包含反斜杠、方括号或不支持的控制字符时不替换，避免破坏引擎标记。没有字体替换或自动字体回退能力，实际字形由游戏字体决定。

## 验证

`scripts/test-catsystem2.ps1` 构建独立的合成 x86 宿主并加载实际原生 DLL，覆盖 UTF-8 与经典分支各两种对象布局，以及错误类型、错误缓冲及错误显示方法的拒绝；经典分支额外覆盖颜色前缀保留与不可编码译文透传；显示缓存独立于正文缓冲，要求显示指令和完成指令才能更新。合同覆盖带标记正文的首代、次代、相同译文重试、Unicode 原样传递、含标记长度边界、停用可见恢复，另有只运行历史容器、不运行行回调的显示/换代/重试/恢复及 Host 重入合同，以及完整采集、首代和次代替换、移除译文、无效输出、追加、重入、外部改字、隐藏恢复、对象复用、资源上限和恢复超时。

实机可见结果及其适用范围记录在 [当前 Work 调查](../../../../../flightdeck/work/adapter-coverage-and-x86/references/catsystem2-dialogue.md)。合成合同不能代替实机字体、布局、刷新与恢复验收。
