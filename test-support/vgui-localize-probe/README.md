# 本地化查询探针与单标签替换实验

Frida 诊断工具，观察 x86 thiscall 的名称查询、索引查找及按索引取值。它使用 Interceptor 的进入/退出通知，只读取原函数的参数与返回值，不调用本地化表编辑方法，不修改参数、寄存器或返回值，也不属于产品 Adapter。

以上为默认只读模式。显式使用 `--allow-replacement` 才加载 `replacement.js`，允许对一个指定 token、指定原文替换返回指针；原始表和原函数参数保持不变。这是受控实验，不是通用生产缓存或已交付适配器。

## 验证

环境需要 Python、Frida Python 包和 MSVC x86 工具。若 Frida 安装在独立目录，通过 `GLYPHSHIFT_FRIDA_PYTHONPATH` 提供，不含开发者机器路径回退。

运行 `scripts/test-localize-query-probe.ps1` 会编译独立 C++ 宿主并附加探针，检查：

- 方法字节不匹配时，在安装观测前拒绝；
- 真正的 x86 名称/索引调用均能采到完整文字；
- 函数返回文字及 LastError 不变；
- 停止观测后不再产生记录，原调用仍正常。

这是探针自身的原生观测合同，比纯生命周期模型多了实际进程附加，但仍不是任何目标软件的 ABI 自动认证。

`scripts/test-localize-query-probe.ps1 -Replacement` 另验证：名称/索引替换、换代后重新设置控件文字、停用后重新设置恢复、旧指针在脚本卸载后仍有效、原始表不变、调用者修改缓冲后的禁用、过期代次及预算拒绝。

合成宿主先卸载脚本并核对旧指针，再正常退出，最后释放诊断会话，避免代理断开与宿主 ExitProcess 交叠。旧清理顺序曾有偶发退出超时，保留为失败证据；调整后连续三轮正常退出。真实目标模式只停止/卸载探针并断开会话，不结束目标进程。

## 受控替换

启用替换时可额外指定 `--control-file <local-control>`，命令 JSON 使用唯一 `id` 和 `action`。`publish` 携带 `policy`：递增整数 `generation`、`token`、`source`、`translation`；其他动作是 `status`、`disable`、`stop`。控制器以同名 `.ack.json` 原子写出对应 id 和状态。停止时应先核对确认文件再判断进程退出，避免误报已完成的停止请求。

仅接受短的单行非格式化标签，每段最多 256 个 UTF-16 单位。先核对 token 与原文，嵌套查询仅在外层替换，避免重复改写。`disable` 恢复后续查询，已复制文字的控件需重新设置/重建；此工具不提供自动刷新所有现有控件的保证。

`returned_text.py` 从控制端为目标分配可写数据页，每个会话最多 16 次分配，每次提交一个系统页。它不覆盖原表，发布后不立即释放旧页，即使发生不确定的 RPC 失败也保留可能暴露的指针。数据页保留至目标进程结束，独立于 Frida 脚本的垃圾回收；这避免悬空指针，但不是适合长期无限会话的资源管理方案。检查到返回缓冲被调用者改写时停止当前替换，未承诺任意并发可写调用者兼容。

## 授权目标入口

`run.py --config <local-config> --output <local-evidence> --seconds 20`。可选 `--phase-file <local-phase-file>` 将新记录按界面操作阶段区分。输出必须位于仓库的本地测试目录。

配置包含 `pid`、接口 `object` 指针、所属 `module` 名及 `methods`。三个方法键为 `find`、`index`、`value`；每项提供 `slot`、函数 `address`、16–64 字节的十六进制 `prefix`。这些全部是单次机器输入，不得提交。必须先由调用链和调用约定检查确认语义，不能仅根据接口版本名填写槽位。

脚本再次检查当前对象虚表、地址、所属模块、可执行内存及方法字节，所有检查完成后才附加。匹配字节只是拒绝错版本/过期配置的防线，不是对输入配置来源的信任证明。

## 范围与限制

- 仅读取匹配接口对象的调用，最大 2,048 个 UTF-16 单位；最多记录 512 种阶段/来源组合，索引名称缓存最多 2,048 项。
- 索引关联的 token 是最近观察到的映射；不能把它当成跨资源重载的稳定身份。空 token 不代表没有完整原文。
- 格式化查询未单独拦截。原始格式串中可能仍有占位符，必须区分它与最终可见文本。
- 名称/索引记录可能重复同一原文；这是诊断证据，不直接写入产品采集目录。
- 计时结束或异常退出时卸载脚本并断开会话，不结束授权目标进程。测试模式只正常结束自身创建的合成宿主。
- Frida 仅用于受控实验，不加入 Runtime Bundle。默认只读；显式替换模式也仅验证指定标签的返回值替换及重建后的恢复，不自动刷新旧控件。
