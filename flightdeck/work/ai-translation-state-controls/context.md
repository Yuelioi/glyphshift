# 稳定上下文

## 状态语义

- 确认 AI 翻译是计费/用量前的最后决策点，必须显示当前 AI Profile 名称、协议与模型；规模和批次策略
  不能替代执行身份。
- 全局同时只有一个活动任务。重复发起失败提示属于页面级可恢复消息，关闭提示不停止、清除或隐藏真实
  后台任务；用户仍可从标题栏进入任务页。
- 批次详情是诊断视图，不是任务本体。折叠只改变占用空间；关闭终态详情只 dismiss 当前 job 的页面
  报告，不删除历史、不回滚译文、不停止任务。
- dismiss 必须按稳定 job ID 记忆。后台轮询再次返回同一个终态 job 时不得重放；新 job 可以重新显示。

## UI 决策

- 确认 Modal 在待翻译规模之后显示“AI 配置”和“模型”，使用当前任务即将解析的 Profile 快照。
- 批次详情标题行始终提供折叠/展开；终态另提供关闭。运行中折叠后保留整体进度摘要。
- 错误 Alert 使用 Nuxt UI 可访问关闭动作；关闭按钮具有明确名称，中英文一致。
- 紧凑窗口中身份值允许换行/截断但不隐藏，折叠控件保持键盘可达并暴露 expanded 状态。

## 验收

- Dictionary 与 Probe 共用确认组件，均显示正确 Profile/模型。
- 活动任务冲突提示关闭后消失，后台任务入口仍可见。
- 终态详情关闭后，在同 job 轮询更新中保持关闭；新 job 自动恢复显示。
- 运行中和终态详情均可折叠/展开；关闭不影响结果、历史或 Token。
- 只运行 AI/Probe/Dictionary 定向门禁；归档 UIA 不属于本 Work。
