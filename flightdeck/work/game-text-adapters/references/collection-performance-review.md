# 采集、字典合并与筛选的静态性能检查

## Scope

检查短时间大量文字进入后，状态读取、排除集合、自动追加、列表查询和过滤是否重复全量处理。只做代码检查，未执行真实软件压测，以下是已确认路径与待验证优化，不是实测耗时结论。

## Findings

- `CaptureView.poll` 每秒读取摘要；自动补全间隔 0 每 250 毫秒也读取摘要。`probe_run_summary` 调用 `collect_workflow_sources`，因此状态查询会执行原文合并检查，并非轻量只读操作。
- `probe_entries_snapshot` 每次遍历附加字典构建排除原文集合，复制写入字典生成快照。`uncollected_sources` 与 `query_entries` 都会走 `combined_rows`。观测读取由 JSON 文件解码，并重复构造映射与归一化结果。
- 新原文批次通过 `update_dictionary` 重建完整字典 artifact，验证关联启用工作流，序列化并原子替换整个文件。仅在存在新原文时执行，但短时间多个批次会重复整本处理。
- 查询先构造全部组合行，再执行小写搜索、状态/适配器过滤、按最后出现时间排序，最后分页。前端分页限制 DOM 数量，未限制后端每次查询的全量计算。
- 字典隐藏规则在后台线程分类，正则按一次调用编译，已有基础保护；新增原文或规则变化会重新提交完整原文数组。工作流实时筛选应复用按原文及规则版本缓存，不能在每次刷新时重新全量分类。
- `CaptureView` 的定时 poll 没有自身在途保护；页请求编号只丢弃旧响应，不取消已经发出的后端工作。慢查询可能堆积，也可能因最后出现时间变化引起行顺序移动。
- 采集已有按原文及适配器去重、次数累计和容量限制；列表已有分页、搜索防抖、版本比较及过期响应保护，保留这些机制。

## Suggested order

1. 分离轻量摘要读取与有副作用的采集追加；每轮共用一份观测/字典快照。
2. 以观测、字典及规则版本维护增量索引，缓存排除集合、组合行、搜索文本及过滤结果。
3. 新原文批量追加，合并持久化频率；内存可见、AI 待译和实际写盘采用明确独立边界，验证停止/退出刷盘。
4. 列表请求合并且只允许一个在途刷新，视图未变化不替换当前页；验证编辑、选择与滚动位置稳定。
5. 建立合成基准：不同字典规模、重复率、附加字典数量、规则数量与突发批量；覆盖 AI 写回、搜索中新增和翻页并发。首先记录全量重建次数、读写次数和查询延迟，再评估是否需要增量日志或存储迁移。

目标软件文字重绘和 Glyphshift 列表刷新分别验证。隐藏规则只影响视图及既定 AI 跳过语义，不静默删除采集原文；附加字典原文排除和适配器声明的归一化语义保持一致。


## 已实现的第一轮优化

- 摘要命令不再追加字典。独立采集命令每秒检查持久化观测批次，不调用目标文字刷新；AI 准备计划时也先收取最新批次。停止工作流收取末尾批次，AI 字典锁导致的等待在解锁后重试；失败不记作成功版本。
- 写入字典与附加字典按 ID、revision 复用共享快照，未变化批次跳过追加检查。追加检查只做归一化原文集合的存在性判断，不构建展示行；仍保留空译文排除与忽略原文语义。
- 采集文件按真实内容比较后复用解码、归一化结果，不依赖 mtime/文件长度猜测更新。组合行、排序和小写搜索文本按输入失效；分页只复制返回页。缓存仅保留一个当前记录，避免访问历史记录导致无界增长。
- AI 计划一次取得固定完整快照，取消按 200 条循环重复查询。
- 前端分页请求串行，连续搜索和切换筛选只补发最新请求；过期结果不覆盖页面，卸载取消等待项。同一记录摘要请求共享在途 Promise，跨记录不返回错误的当前选中摘要。内容未变不替换页面数据。
- 字典和工作流共享有界原文分类缓存，规则变化重新编译并清空结果；上限为 50,000 项与 8 MiB 原文字节。字典分类请求也合并；工作流新增隐藏开关，在后端分页和总数统计前过滤，不删除原文。

## 验证

- `cargo test -p glyphshift-capture --lib -- --nocapture`：30 项通过，含新大字典/缓存失效与原文追加合同。
- 合成 10,000 原文、5,000 字典条目、连续 20 页：缓存路径约 138 ms，强制每次清缓存重建约 2.32 s；缓存路径解码与行构建各 1 次。该结果是同一实现的冷热对照、调试构建单机数据，不等同于旧版本完整基准或真实游戏帧率。
- `cargo test -p glyphshift-desktop-shell --lib -- --test-threads=1`：99 项通过；末尾等待重试调整后又运行 5 项 collection 合同通过。
- `cargo test -p glyphshift-ai-translation source_filter_cache_tests`：1 项规则缓存合同通过。
- Vue 类型检查通过。自动补全、工作流隐藏、慢查询筛选合并、请求队列及字典隐藏共 13 项不同 Playwright 流程通过；工作流工具栏截图已检查。

## 保留边界

本轮不修改目标 Adapter 重绘算法，不引入延后写盘的内存字典或日志存储。新增条目仍按批次完整原子保存字典；避免重做无变化批次，但首次大批次依然有完整构建成本。文件内容读取与筛选扫描仍存在，缓存失效后也需要重建，不宣称已完成全面增量索引。若实机仍慢，再以真实阶段耗时判断是否扩展多记录缓存或迁移存储。

新交互已通过 review-app 脚本构建、校验并启动；本地 0.3.0 NSIS 安装包已生成并解包校验，供用户分发测试。Unity 字体回退等原有未完成项仍保留。
