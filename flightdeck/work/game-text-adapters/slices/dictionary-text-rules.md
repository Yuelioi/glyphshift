# 字典文字规则与固定局部标签

Status: Implemented

## 已确定契约

全局文字处理只保留不再收录过滤。正则替换仅存字典元数据 `textRules`，无全局配置、迁移或兼容分支。独立变量 `{{TR}}` 表示第一组的所属字典译文；旧试验变量写法已移除。规则按工作流字典顺序及字典内部顺序先匹配，命中不回退到完整词条或其他字典。无匹配才查完整词条。

规则与字典导入导出及发布更新同行。收录按同一模板提取待翻译固定文字，规则所属字典是写入字典才追加；附加字典规则不向其他字典追加。自动翻译归一并去重输入，写回检查当前规则。关闭规则恢复完整原文处理；历史词条用户自行删除。

## 当前实现

- package 和 desktop metadata 增加规则及严格正则校验，字典修订触发运行代次与缓存更新。
- Workflow 编译保留按字典排列的规则，以及独立的所属字典查词位置，避免合并后借到别本译文；wire 发布和摘要包含规则所有者和顺序。
- capture 使用同一模板的 collection_sources；规则优先的只读显示，规则缺译文不显示历史整条译文。
- AI 规划拆分动态原文并去重，写回接纳已观察固定文字，拒绝当前规则已改写的旧动态原文。
- 全局设置字段和入口删除。字典元数据表单承载规则编辑/测试；确认规则加入草稿，保存字典持久化。新建路径携带 textRules。
- 设置页改帮助页同款图标/活动线标签；两处滚动固定。Playwright 实际滚到底部位置检查和截图通过。

- 字典包规则往返及无效规则拒绝合同通过；发布 wire 所有者、顺序和摘要验证通过。

## 规则行直接编辑修正

移除字典页“隐藏跳过的条目”及仅供该功能使用的分类 IPC；历史条目继续可搜索编辑，不清理用户数据。工作流文字列表同名开关一并移除；默认隐藏全局过滤命中项，选择“已跳过”状态时可查看原因。

规则行不再一律只读。规则属于写入字典且引用一个固定词条时，投影给出 editSource/editTranslation：聚焦显示固定词条译文，失焦显示规则生成的完整结果。手动写回在服务端重解析当前规则并写入固定 key，清空与批量清空沿用相同映射；附加字典和纯字面量规则拒绝从这里修改，避免整串动态原文污染字典。保存期间继续输入不会被旧请求清除脏状态。
