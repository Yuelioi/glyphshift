# 软折行去重

Status: Implemented; target acceptance pending

用户确认翻译生效后，发现同句因不同折行位置产生三条历史词典记录。只读副本验证确认是空格后 CRLF 的位置差异，译文存在不同措辞，不能直接删除或任取其一。

## 实现

- Native Adapter 通过可选 source-policy export 声明策略；缺省 Exact，不改变现有 ABI 结构。MonoGame 选择 SpacePaddedSoftWrap，fixture 保持 Exact。
- Domain 提供共享归一化；Runtime 采集和查找使用同一键。旧键精确查找兼容，无冲突的历史别名可跨宽度复用，冲突不随机挑译文。
- Capture 对历史目录和词典作只读投影，合并次数、时间与来源。混选适配器只归一化实际由对应来源观测的键，保护 Exact 来源。
- 无统一条目且已有译文不同时显示行内选择。用户保存统一条目后优先采用；旧数据保留，只有明确清空操作才清除对应历史键。AI 跳过冲突并保护已有译文。
- 平铺译文依据原始字体行宽和替换字体度量重新折行；明确带换行的译文保持原样。

## 验证

- Domain 与 Capture：25 项通过，覆盖历史保留、合并、冲突、统一条目优先、忽略、清空与混合来源。
- 真实 MonoGame Runtime 合成绘制回归通过：两个折行宽度、规范化采集、旧键兼容、冲突保守回退及既有字体与恢复场景。
- CoreCLR 34 项断言和 Native Loader 合同通过。
- Playwright 桌面和窄屏冲突选择通过；选择提交统一键且保留历史条目。
- Desktop cargo check --tests 通过。
- 提交前 scripts/test.ps1 活动包回归：477 项通过，17 项按声明忽略，零失败；归档 UIA 不在作业范围。
- 用户数据副本投影：相关查询从 4 行变为 2 行，完整句三合一，独立单词保留，标出一条冲突；未修改原数据。
- scripts/review-app.ps1 -UseUserData 同步 Release 构建并启动成功；生产 Loader 在打包前后均校验通过 10 个 Adapter，继续读取原用户工作区。

## 边界

仅识别拉丁词之间恰好一个 ASCII 空格后接单个 LF/CRLF 的形态；保留普通换行、空行、缩进、双空格与冒号标题。形态完全相同的手工换行无法仅凭字符串区分。当前规则不推广到所有语言、所有 Adapter 或自绘字形。

驻留组件需目标退出再启动才能更换。新版实机的重复采集与布局仍待用户复核；不强制终止目标。
