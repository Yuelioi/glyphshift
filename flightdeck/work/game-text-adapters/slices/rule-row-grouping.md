# 规则翻译行合并

Status: Implemented; review app launched

## Behavior

工作流列表默认合并规则翻译。在“任务操作”提供同名勾选项，关闭即可查看各动态原文，选择按工作流列表状态保存。此次只整理列表，不删除捕获文件或字典词条。

按字典归属、规则序号及规则提取的固定原文组合分组，同规则的 Selected 和 Total 不会合并，跨字典亦不混合。保留最近观察的代表行，累加匹配记录的次数并合并适配器，第一次出现时间取最小值。忽略行和没有固定词条的普通替换不分组。

分组在筛选后、分页前执行，搜索特定数值时可定位对应原文。使用已有观测行缓存与一次分组索引，不持久化规则分组结果，规则或字典修订立即参与下一次查询。停用规则恢复原始记录，不引入迁移或排除集合。

输入期间固定当前代表行，使用规则固定词条的稳定行标识；保存仍按已有固定 key 路径写入，失焦后恢复最近数值显示。
