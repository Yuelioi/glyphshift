# 文字处理与收录过滤

Status: Implemented

## 范围

按用户要求，把原通用设置中的文字过滤与正则替换规则合到“文字处理”。过滤从只影响 AI/显示改为命中的新原文不再自动收录到工作流写入字典。

## 实现与边界

- 设置导航“文字处理”下依次显示“不再收录”“正则替换规则”，保持各自保存行为，通用页移除重复入口。
- 自动收录在批次写字典前复用保存的 FilterPolicy 和 SourceFilterCache；启动时先加载策略，保存策略时使收录版本缓存失效，无新观测也能重新检查。
- 默认过滤纯数字/符号、数值单位、单字符、网址、邮箱、路径、快捷键；含任意数字仍是独立且默认关闭的激进选项。
- 修正旧数值单位分类对任意冒号/斜线加数字的误判；比例/尺寸仍过滤，`Selected:0` 不再被错误过滤。
- 既有字典记录、人工编辑/导入保持原行为，不追溯删除。原始观测仍可用于“已跳过”来源解释；列表隐藏是独立显示选择。本轮没有清理用户已有数字条目。
- 关闭规则会让原有观测重新具备收录资格；启用规则不删除已经收录的条目。设置仍沿用已有存储键，无破坏性迁移。
