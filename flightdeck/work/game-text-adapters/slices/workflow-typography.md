# 工作流拥有字体与字号

Status: Complete

## Decision

字典内容独立于显示效果。工作流保存默认字体候选与默认字号，并以字典 ID 保存 `fontPolicy.dictionaryOverrides`。单个字典的字体、字号分别留空时继承默认值；显式 100% 保留原字号。原文冲突按最终命中译文的字典选用对应覆盖。同一字典在不同工作流里可以独立配置，复制工作流会复制覆盖，移除绑定会移除对应覆盖。

核心组合模块的 Dictionary 不再携带字体属性；旧字典文件中的字体字段只用于格式兼容，不再送入运行时决策。旧工作流的 `preferDictionary` 不再是显示模式。字体与字号仍按适配器的实际能力分别下发，未新增适配器能力。

## Result

- 常用字体新增 8 组 Windows 推荐字体，名单由前后端共享 JSON 维护，匹配实际安装的字体并按中英文别名去重。首次无收藏配置时初始化并保存；既有收藏（含主动清空）保持不变，设置页可手动“添加推荐字体”。参考 [Windows 字体清单](https://learn.microsoft.com/en-us/typography/fonts/windows_11_font_list)。原生初始化/重开合同 1 项、字体管理 Playwright 2 项、类型检查通过；本地截图检查通过。本项尚未重建桌面 App。
- 工作流字典行内提供字体搜索、全部/常用字体筛选及字号输入；窄窗口将显示设置放在第二行。
- 字典编辑表单移除字体和字号；工作流默认设置保留在字体策略页。
- 工作流创建字典使用共享 LanguageSelect，支持语言管理列表及自定义代码。
- FieldHelp 提示高于模态窗口；字体选择后收起，避免干扰下一字段输入。
- 关于页增加在线文档及发布页面，文档 URL 已加入桌面 opener 权限。

## Validation

Vue 类型检查通过。12 项核心组合、22 项后端、27 项桌面工作流合同通过；覆盖译文优先级、分别继承、配置保存/复制、非法比例与未选字典覆盖拒绝。6 项相关 Playwright 流程通过，新增流程验证常用字体、语言下拉、字号保存和重开后清除覆盖，确认未修改字典元数据。宽窄截图检查通过，本机证据留在 local-test。

## Next

此配置所有权作为 Unity 缺字回退接入的基础。实际字形生成、覆盖检查与恢复仍按 [Unity 字体回退](unity-font-fallback.md) 验收，不将本次设置功能视为游戏字体修复。
