# 收集列表的处理状态与来源

Status: Implemented

## 用户决定

保留正常原文与译文显示，删除收集列表里过时的单条、批量“添加译文到字典”按钮。通过状态与来源解释字典、规则与过滤结果，为多字典归属展示留出结构；完整联合表另行设计。

## 实现

- 译文仍在原输入框显示、编辑后自动保存；列名简化为“译文”。
- 状态区分已翻译、未翻译、规则翻译、规则待译、规则置空、已跳过、译文冲突。
- 来源显示规则编号、精确条目的“已在某字典”，以及规则查词的“译文来自某字典”。跳过说明复用实际文字过滤分类，包括数字/单位/网址/路径/快捷键/自定义正则等；手动忽略单独说明。
- 分页和搜索前投影状态及最终译文，支持已跳过、规则匹配、其他字典筛选；新筛选可持久化。
- 已观测且属于附加字典的原文可显示归属和译文，标为只读，并提示到所属字典修改。候选译文与批量清除尊重只读。收集排除、AI 写入与字典拥有者规则保持原有边界。
- 投影按工作流附加字典优先级查词，完整原文译文优先于正则；读取列表不新增或更改字典条目。未观测的附加字典条目不加入本轮列表，不构成完整联合表。

## 语义边界

状态是当前配置的解析结果，不是目标软件已经完成像素替换的回执。过滤状态解释收集/AI 文字过滤。

用户截图中 `Selected:0 → 选择` 属于完整原文直接翻译，会明确显示字典命中；本轮不把该记录自动改写为属性词条，也不自动补回数字。规则仍使用已实现的捕获查词模板；魔法变量重命名和现场布局对齐没有在本轮变更。
