# 托盘与窗口置顶

Status: Implemented and packaged

## Behavior

- 通用设置增加“最小化到托盘”和“窗口置顶”；关闭行为增加“收进托盘”。默认仍是普通最小化、关闭退出、不置顶。
- 标题栏图钉与设置同步，保存置顶偏好，启动时应用。设置失败回滚原生窗口状态。
- 托盘使用产品图标，左键恢复窗口，右键显示菜单。退出菜单先恢复主窗口，再走现有未保存编辑、AI 任务和运行效果清理流程，忽略关闭收进托盘的偏好。
- 托盘隐藏前验证图标存在；系统最小化事件也遵循最小化偏好，隐藏不停止工作流。
