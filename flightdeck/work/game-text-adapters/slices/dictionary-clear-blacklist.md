# 捕获过滤、清空与列表排序

Status: Implemented; review app launched

## Current behavior

全局文字过滤命名“捕获黑名单”，只描述匹配行为。字典页和工作流列表不再提供旧隐藏开关或“已跳过”筛选。

清空字典通过独立参数 clearCaptured 表达用户操作，停止关联记录的采集写入，删除当前观察文件，再恢复原来的工作流启用/收集状态。空字典仍允许清空。普通编辑不重置捕获。清空后相同原文、新原文均可正常重新收录。

此前错误引入的删除排除集合已从存储、自动收录、列表投影和计数逻辑完全移除，不做迁移或持续排除。旧实现把清空误当成长期排除，用户现场已证明其错误；不得恢复该设计。

字典来源只标注额外字典；写入字典不重复提示。规则序号、只读与翻译状态保留，判断依据是归属而非字典数量。

工作流和本地字典库支持最近使用（默认）、最早使用、名称升序、名称降序。打开或启动更新使用时间，本机持久化排序与使用时间，不写入分发字典。排序发生在筛选后、分页前，切换回第一页。
