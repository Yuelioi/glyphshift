# PotPlayer

当前决定：停止字幕缓存适配，保留已验证的使用办法。

## 已验证

- 外挂 SRT 的完整正文曾命中 TextOutW 和 ExtTextOutW。
- 用户验证：保持工作流运行，重新打开同一字幕后，已有译文能够显示；先启动工作流再加载字幕也能生效。
- 仅凭列表里的历史命中，不能认定当前播放重新经过了文字入口。

## 未解决

字幕已生成后，新增或修改译文能否自动刷新，以及停止后的可见恢复，未完成验收。重载成功支持缓存时机这一调查方向，但没有定位具体缓存失效入口。

## 使用办法

先把 SRT 导入字典、补全译文，再启动工作流和播放器、加载字幕。用户已明确取消实时字幕缓存排查，不继续投入，除非重新授权。
