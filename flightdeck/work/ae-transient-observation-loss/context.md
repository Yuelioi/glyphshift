# 稳定上下文

- 用户已明确暂停 UIA 线路；本工作不以重新启用 UIA 回避 Native 绘制与观测传输问题。
- 当前问题同时出现在 AE 2020 与 AE 2022，不能再以 Adobe 主版本差异作为主因。
- “可见文字已替换、Observation Index 无原文”证明故障发生在 Replacement Decision 之前的
  capture enqueue，而不是绘制 Hook 入口整体未命中。
- Adapter 热路径不得阻塞宿主线程，但传输抽取不应与正常入队互斥并把每 250ms 的调度窗口变成
  必然丢失窗口。
- 对话框、弹出菜单和禁用菜单项是短暂表面；验收必须精确触发并分开记录启用态与禁用态。
- 正式修复必须同时构建并验证 Desktop Release 与 Runtime Bundle，不允许只更新界面程序。
- 真实软件路径、进程信息、截图和原始采集继续只保存在本机忽略证据区。
