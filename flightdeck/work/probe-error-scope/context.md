# 稳定上下文

## 产品事实

- 操作失败属于触发它的 Probe Run，不是探针模块的永久全局状态。
- 用户离开详情或选择其他 Probe Run，先前 Run 的操作反馈已经失去当前操作上下文，应自动关闭。
- 异步命令可以在用户切换 Run 后才返回；迟到失败不得显示成新 Run 的失败。

## 约束

- 不按探针名称、软件品牌、Adapter ID 或具体错误文案分支。
- 页面级加载失败可以保持页面级语义；带 `runId` 的命令必须按 Run 隔离。
- 回归使用确定性合成数据；本机路径、真实进程与截图只进入 `local-test/`。

## 验收语义

- A 已显示操作错误时，切到 B 后错误提示不存在。
- A 的异步操作在切到 B 后才失败，也不会让 B 显示 A 的错误。
- 保持当前探针时，操作失败仍照常显示且恢复动作仍可使用。
