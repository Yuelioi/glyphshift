# 稳定上下文

## 产品决策

- 两个仅观察 Adapter 暂时停用：实现源码保留，产品 Catalog、兼容选择、默认方案与 Runtime 运行计划均
  不得继续把它们作为可用能力。
- 停用不是删除 Adapter 领域抽象；未来有可靠用途时可以重新注册。
- 划词翻译不再作为产品能力保留；删除入口、状态、文案、命令和专属测试，而不是只隐藏按钮。

## 约束

- 观察器按能力/注册事实停用，不按 Adapter 展示名、目标软件品牌或 executable 分支。
- 探针的 Text Observation 与划词翻译的 Interactive Selection 是不同领域；移除后者不能破坏探针采集。
- 已持久化的旧 UI 选择或旧命令调用必须安全失效，不能让应用启动失败。
- 真实软件位置、进程与验证证据只进入 `local-test/`。
- 旧 `AppSettings/1` 文件可能仍包含已删除的快捷键字段；桌面设置反序列化时接受并丢弃它，序列化不再
  输出该字段。

## 验收语义

- 新建/编辑工作流与探针看不到、选不到两个观察器，Runtime 也不会调度它们。
- 两个观察器的实现文件仍在源码树中，可由未来注册重新启用。
- 应用中不存在划词翻译导航、悬浮窗、快捷操作或桌面 Command；其专属测试和文案同步移除。
- 现有工作流、探针、词典和软件管理的定向合同继续通过。

## 实现结论

- 产品 Adapter 可用性统一要求 `TextReplace`，不以观察器 ID 硬编码分支。
- Runtime Bundle 清单继续保留空的 `isolated_workers` 与 `acquisition_workers` 数组，以兼容现有
  Bundle schema；构建不再生成或复制对应工件。
- 已持久化工作流若引用不再注册的 Adapter，会在恢复时撤销启用状态并保留定义，避免启动失败或静默
  调度旧能力。
