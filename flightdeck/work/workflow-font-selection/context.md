# 稳定上下文

## 产品语义

- 字体策略属于 Workflow Target；用户选择的是有序字体候选集合。
- 字体搜索只改变可见候选，不得重置或替换已选集合。
- 用户可见字体名称是交互身份；测试使用合成字体，不依赖本机字体目录。
- 字体行提供整行选择命中区；复选框和优先级按钮继续作为独立控件，不能因事件冒泡发生双切换。

## 约束

- 使用现有 Nuxt UI primitive 与工作流编辑状态，不建立第二份字体选择状态。
- 回归测试通过仓库 Playwright runner 驱动真实新建工作流界面。
- 本机截图与字体目录证据只留在 `local-test/`，不进入跟踪文件。
