# 桌面应用行为设置计划

## Stage 1：行为合同

- [x] 设置存储覆盖开机启动与关闭行为的默认值、持久化和非法值拒绝。
- [x] Playwright 覆盖设置页分组、权限状态、持久管理员启动以及两种关闭偏好的选择与持久化。

## Stage 2：Windows 能力

- [x] 查询当前进程是否提升；管理员启动开启时先持久化再立即 UAC 重启，并在后续启动自动遵循。
- [x] 为当前用户配置或移除开机启动，并保持失败可恢复、不覆盖已保存设置。

## Stage 3：界面与窗口生命周期

- [x] 设置页按“外观 / 应用行为 / 权限”组织，复用紧凑配置行。
- [x] 标题栏关闭与系统关闭请求统一遵守关闭行为，并继续保护未保存词典草稿。
- [x] 权限失败文案明确区分“目标已退出”与“可能需要管理员权限”的恢复步骤。

## Stage 4：验证

- [x] Rust、前端构建与桌面 Playwright 通过。
- [x] 使用仓库 Playwright runner 完成中英文、深浅主题和紧凑窗口布局检查。
- [ ] 在独立本地构建上由用户主动完成持久 UAC 开关、开机启动和原生窗口关闭实机冒烟；自动化不得
  改动这些本机状态。
