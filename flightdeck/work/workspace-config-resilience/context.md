# 稳定上下文

## 数据根

- 产品尚未首次发布；默认工作区直接使用 `<roaming-app-data>/Glyphshift/workspace`。
- bundle identifier 继续只承担安装身份与 WebView/Tauri 内部目录身份，不再决定产品工作区文件夹名。
- 显式 `GLYPHSHIFT_DATA_ROOT` 与内部启动参数继续覆盖默认根，供隔离 Review、本机测试和提升重启使用。
- 不在产品代码中探测、复制或兼容当前开发目录；开发机现有工作区在实现验证后一次性搬迁。

## 容错层级

- 未知字段：忽略，不得让 artifact 失败。
- 已知字段值非法：使用字段默认值、空值或安全枚举默认，保留同一对象其他合法字段。
- 记录缺少不可伪造的身份或核心引用：只跳过该记录并产生脱敏警告。
- 单文件 JSON 语法损坏：保留原文件，跳过该文件并产生脱敏警告；不得阻止其他软件、词典、工作流、
  AI Profile 或探针状态加载。
- 写回只输出当前规范结构；不把未知或非法字段重新写回。

## Module seam

- 容错策略应集中在各 artifact store 的读取 interface 或一个共享持久化读取 Module 内，调用者只接收
  “有效内容 + 警告”，不在页面、命令或启动流程重复判断 JSON 细节。
- 严格校验仍适用于新写入请求和运行时不变量；读取用户本地持久数据不能复用整份拒绝策略。

## 验收

- Settings、AI Profile、软件、词典、工作流、探针及 AI 任务记录均完成读路径审计和相称回归。
- 一个字段、记录或文件损坏时，其余合法用户内容仍可见、可继续编辑。
- 默认路径不含 bundle identifier；隔离测试根行为不变。
- 一次性开发数据搬迁完成后，新根包含原工作区内容，源根不再作为产品运行依赖。
- 不运行归档 UIA 测试。
