# 稳定上下文

- 翻译任务页默认突出当前任务；统计用于按 Profile/模型对比，任务列表用于追溯终态记录。
- 统计页按 Profile 筛选；连接协议只是低频诊断字段，默认隐藏但可通过显示列临时查看。
- 管理列表必须复用 `ManagementTableFrame`、`UTable` 和 `useTableColumns`，由共享框架提供搜索、筛选、
  显示列和完整分页。
- 用户明确要求高频、高价值信息直接展示，低频诊断详情收纳或展开。
- Help 是 Read 模式，但必须保留可执行入口，并以一次完整实际工作路径作为默认内容。
- 当前支持简体中文和 English；两种语言必须保持相同信息结构。
- GUI 验证使用仓库 Playwright；最新版桌面应用只能通过 `scripts/review-app.ps1` 构建和启动。
