# 第一版制作方案

用户已要求直接制作第一版查看效果，按自主创作执行，不停在模式或分镜确认。

## 制作约束

- 第一版约 45 秒、1920×1080、30fps；中文标题与字幕，音乐和少量音效，不加旁白。
- 视觉沿用产品暗底、蓝色强调、无衬线字体和紧凑工作台气质，增加电影画幅安全留白。
- 软件 UI 来自真实前端，用固定演示数据截图；AE 效果面板来自已验证的真实截图。
- 不把截图动画表达为连续实际操作录像，不宣称全软件覆盖或虚构性能指标。
- 工程、原始素材和成片均在本机忽略证据目录；不改产品业务代码、不提交或公开发布。
- 已有明确产品设计规范，直接复用 DESIGN.md；省略另起一套静态风格稿，以逐镜头静帧验收。
