# 第二版：多软件、字体、AI

用户反馈要求重排重点：展示多款软件与常见 Windows 应用，使用“词语纵深”镜头表现广度；
单列字体替换与 AI 能力。按已授权的自主修改模式继续，保留第一版。

## 分镜与表达边界

| 时间 | 重点 | 表达 |
| --- | --- | --- |
| 0–8 秒 | 多软件覆盖 | flying-words 词语纵深隧道，软件名称与应用类别铺开；AE、Cavalry、Notepad++ 作为例子，不虚构支持数量 |
| 8–16 秒 | 创作与日常桌面 | 专业软件和日常应用的文字卡，AE 实际中文面板提供真实效果证据 |
| 16–28 秒 | 字体替换 | 实际字体策略界面，搭配同一句话的雅黑/宋体/楷体字样比较，标注排版示意 |
| 28–40 秒 | AI 辅助翻译 | 显示支持的 AI 服务名称与真实探针译文界面，强调多服务、批量补全、手动校对 |
| 40–45 秒 | 三个能力一起复用 | 界面翻译、字体替换、AI 辅助组合，工作流作为落点 |
| 45–52 秒 | 品牌收尾 | 保留已有 logo 收束与字标落定，改成三能力收束文案 |

- 已由 Gallery 索引确认 `flying-words` 同名变体，完整读取配方卡及
  `demos/typography/flying-words/FlyingWords.tsx`，下载参考样片供本机对照。
