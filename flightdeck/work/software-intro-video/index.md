# 软件介绍视频

Status: Finished

## Goal

制作无需用户手动录屏的 Glyphshift 软件介绍视频；按反馈突出多软件覆盖、字体替换与 AI，
交付可播放 MP4 供审阅。

## Current

第二版已重排为用户要求的三个重点：词语纵深开场表现软件与界面范围，AE/Cavalry/Notepad++
作为软件例子，独立字体段展示三种字形，AI 段展示服务选择与译文。52 秒、1080p、30fps，
带音乐/无音乐两版保留，第一版文件未覆盖。真实 UI 使用固定演示数据，字体变化明确标注排版示意。
工作台已切换到第二版，六个采样帧与原合成逐像素一致。裁切边缘、字体示意标注、AI 遮罩已修正，
最终成片独立复检通过，可交付审阅；两版完整解码通过、音轨无削波。听感和严格卡拍仍未人工试听验收。

已使用 video-shotcraft 与 Remotion 完成第一版：45 秒、1920×1080、30fps，中文标题与字幕，
带音乐和无音乐两版 MP4，保留音效，没有旁白。产品画面为真实前端配固定演示数据，AE 对比
来自真实效果面板。全部素材、工程和成片只在本机忽略证据目录，未提交或公开发布。

已完成逐镜头静帧检查和独立终检；两版视频画面完全一致，音轨不同，无削波、异常黑帧，
完整解码通过。首次审查发现的字幕偏小、片尾居中问题已经修正。动效工作台经 Windows 路径
适配可打开，六个关键帧与原片逐像素一致；其 Windows 导出按钮未另行验收，交付以 MP4 为准。

残余限制：第一版音乐听感与精确卡拍未完成人工试听验收，AE 原始截图文字清晰度受原分辨率
限制；缩放截图用于表现产品效果，不代表连续操作录像。

## Next

None。第二版已完成，等待用户进一步的创意反馈。
