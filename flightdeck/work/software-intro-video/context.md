  外部桌面软件需要另外安排真实素材采集。

- 英文版根据当前产品与适配器调整，当前展示以通用 Windows 工具和多语言为主，不再聚焦 AE 或 CG；用户允许模拟界面展示语言切换，以验证证据限定支持，不按品牌或框架推断完整覆盖。
