# 稳定上下文

## 产品语义

- 用户选择具体 Adapter；Platform 与 Technology 是兼容和分类事实，不是可激活对象。
- Adapter Plan 属于单个 Workflow Target；切换软件目标不能共享或覆盖选择。
- 全选只作用于当前目录中产品可用的 Adapter，并可再次操作为取消全选。

## 界面方向

- 使用一张连续紧凑表格，列为选择、Adapter、Platform、Technology、说明。
- 分类进入列，不再用分段卡片或重复分类标题打断阅读。
- 表头复选框支持未选、部分选中和全选状态，并提供可访问名称。

## 约束

- 普通界面不展示 Adapter 内部 ID、DLL 或技术入口。
- 保持现有深浅主题、密度与 Nuxt UI 组件体系。
- 测试只使用合成 Adapter；截图与真实本机目录不进入跟踪文件。
