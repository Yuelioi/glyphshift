# 稳定上下文

- Settings 与 Help 都由标题栏图标进入，属于同一层级的独立工具页，不是管理列表或带返回动作的资产详情。
- Settings 与 Help 共享 `UtilityPageShell`：全宽 64px 详情标题带，内部标题与 980px 内容列共轴，标题后
  保留 20px，滚动区对称预留滚动条空间。
- Help 的信息顺序保持“常见问题恢复 → 产品模型 → Adapter”，只统一页面壳层，不改变功能或术语。
- 支持基准为 1520×720 与 960×640、深色与浅色、中英文；页面与 Adapter 列表不得横向溢出。
- 本机视觉证据只进入忽略的 `local-test/`。
