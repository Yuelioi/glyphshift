# Probe 任务动作与临时命名

Status: Complete

## Goal

让 Probe 详情页在宽、窄窗口中都只突出当前任务需要的少量动作，并用普通用户可理解的名称表达临时资产；
不改变 Probe 生命周期、保留、释放或清理的后端合同。

## Delivery

- [x] 详情页头只保留“运行软件”、当前采集状态动作与一个具名任务菜单。
- [x] AI 补全入口移动到条目表工具栏，使翻译动作与其作用对象相邻。
- [x] 临时任务的保留与清理动作收进“临时任务”菜单，危险项明确说明会清理临时资产。
- [x] 临时 Probe 在详情状态和绑定词典区域显示“临时”身份，普通界面不展示内部词典 ID。
- [x] 常规任务的设置、导出与释放连接集中到“任务操作”菜单，现有能力和确认流程保持可用。

## Acceptance

- 960×640 与 1440×900 下，详情页头持续动作不超过三个，标题和状态不会被低频动作挤压。
- AI 补全入口位于 Probe 条目表工具栏；没有 AI Profile 时仍可从同一位置进入配置。
- 临时任务菜单提供“保留为常规任务”和“结束并清理临时资产”，清理仍经过原确认对话框。
- 系统生成的 `quick-dictionary-*` 标识不会出现在详情摘要、绑定词典条或任务列表的可见文本中。
- 绑定词典暂不可用时，界面显示可理解的缺失状态且不会提供无效的打开动作。
- 中英文定向 Playwright、生产构建、Impeccable 检查与深/浅色代表性复核通过。

## Current

名称，低频与危险动作通过具名菜单分组，生命周期与后端合同未改变。
