# Glyphshift 软件图标设计

Status: Finished

## Goal

为 Glyphshift 设计三个原创、可在 Windows 任务栏与应用标题栏清晰识别的软件图标方向；经用户选定后，再制作确定性矢量母版并导出正式 ICO/PNG 资源。

## Current

用户选中的“以方案 1、3 为参考生成的两稿”第一稿已从原始高分辨率生成图直接描摹为纯色 SVG；画布比例、蓝白边界和中央光标均按用户截图对齐。标题栏、原生资源与 Release EXE 现使用同一轮廓。

## Next

None

## Progress

- 已审计现有图标资源、Tauri 配置、产品定位和界面色板。
- 已确定小尺寸优先、强轮廓、无文字、无渐变的共同约束。
- 已使用内置图像生成工具完成三个独立概念稿；生成图仅用于方向判断，未写入正式资源。
- 已按用户偏好的 1、3 方向补充两个混合变体，并将 1、4、5 作为优先收敛候选。
- 用户选定 4“光标回环”；已完成 SVG 母版与 PNG、ICO、ICNS 导出，并在 Tauri 配置中显式登记。
- 前端标题栏已移除旧字母 G，直接复用同一 SVG 母版，避免界面品牌与原生资源漂移。
- 16/24/32/48 像素检查、Playwright 品牌合同与实际截图、生产构建、同步 Release、9 个 Runtime Adapter 校验及 EXE 嵌入图标提取均通过。
- 首版矢量误把参考稿对称化并改变光标颜色；已按用户截图修正为斜向错位交织与暖白光标，重新完成全部导出和验证。
- 最终改为从原始第一稿直接描摹而非凭坐标重构；正式 PNG/SVG 与用户截图的蓝白轮廓重合度为 0.9341。
- 发现图标文件变化没有触发 Cargo 重新嵌入 Windows 资源；`build.rs` 已声明 `icons/icon.ico` 依赖。全新 Release EXE 提取图标与用户截图重合度为 0.9172。
