# 图标概念方向

## A：字形交织

两段抽象字形笔画相互穿插，负形形成轻微的位移轨迹。重点表达 Glyph 与 Shift，品牌独特性最高。

初稿评价：轮廓最紧凑，缩小后仍容易识别，也是三个方向里最接近可注册品牌符号的一稿。正式化时应去掉生成图中的轻微光感，改成完全均匀的色块。

## B：运行时传送门

用紧凑的软件窗口 / 门框和穿越分界线的字形块，表达文本在目标软件内部原位转换。产品含义最直观。

初稿评价：功能含义一眼可懂，但窗口、分界与传输点在 16 像素可能过细。若选中，需要把它收敛成门框、分界和两个状态块三类形状。

## C：适配层

三个错位叠合的平面围成文字光标形负空间，表达词典、工作流与 Adapter 的组合。系统感与扩展性最强。

初稿评价：三块结构与产品架构呼应，色彩也最完整；风险是容易被理解成普通模块或同步标记，正式化时需要强化中央文字光标负形。

## 4：光标回环

把 1 的两段交织轮廓与 3 的中央结构合并为上下咬合的紧凑回环，中央以竖向负形明确指向文本光标。品牌轮廓、运行时变换含义和小尺寸潜力最均衡。

## 5：三阶位移

把三层结构改造成三条逐级收缩的折线笔画，以一致方向表达文本穿过词典、工作流和 Adapter。运动感最强，但正式化时需要避免与通用返回 / 导航箭头相似。

## 共同生成约束

- 单一居中图标，不带名称、字母或说明文字。
- 扁平矢量风格，最多三种颜色，禁止渐变、3D、发光、阴影和 mockup。
- 轮廓在 16 像素仍应可辨认，避免细线与零碎切口。
