# 稳定上下文

## 产品含义

- Glyphshift 是 Windows 上的通用运行时 UI 文本替换与翻译工具。
- 核心组合包括词典、工作流与 Adapter；图标应表现转换能力，不应绑定某个被探测软件。
- 产品名中的 Glyph 与 Shift 可以转译为“字形”“位移”“前后状态”或“适配层”，但不宜直接写出字母或中文字符。

## 视觉约束

- 优先保证 16、24、32、48 与 256 像素下的辨识度。
- 使用扁平几何、强轮廓和充足留白；避免渐变、玻璃、发光、3D、细碎装饰和摄影式 mockup。
- 主色沿用钴蓝 `#6C8CFF` 与石墨黑 `#0C0F14`，可少量使用薄荷绿 `#6ED2A7` 或暖白。
- 不使用通用 AI 星芒、地球、对话气泡或品牌相关宿主图形作为主识别物。

## 交付策略

- 当前阶段的生成图只用于方向判断，不直接进入正式应用资源。
- 选定方向后，以代码可控的 SVG/矢量路径重建，再导出多尺寸 PNG 与 ICO 并接入 Tauri。

## 最终决策

- 正式方向是“以方案 1、3 为参考生成的两稿”中的第一稿。几何轮廓必须直接继承原始生成稿和用户确认截图，不再以名称或口头方向重新概括。
- `src-tauri/icons/icon.svg` 是确定性母版；标题栏直接导入该文件，原生 PNG、ICO 与 ICNS 从它生成。
- 正式图标只使用纯色色块，不继承概念生成图中的渐变、发光或阴影。
- Windows 原生图标由 `icons/icon.ico` 嵌入；`build.rs` 必须声明它为 Cargo 变更输入，保证图标更新触发 EXE 重新链接。
