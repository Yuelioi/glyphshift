# 稳定上下文

- 发布受众首先需要知道 Glyphshift 解决什么问题、适合谁、如何完成第一次界面翻译；仓库拓扑和开发
  命令不能占据 README 主体。
- 设置页仍是立即生效的单列 Windows 桌面设置表面；合并分区不能移除 AI Profile、翻译前确认、
  快捷键、启动行为或权限功能。
- “AI 翻译”应同时包含执行偏好和连接配置：执行前是否确认属于同一工作流的全局偏好，供应商、模型、
  批次、并发、超时、重试和过滤规则属于可复用 Profile。
- 帮助页优先回答首次使用、没有捕获到文字、软件未启动、权限不匹配和如何组织软件/词典/工作流；
  Adapter 技术详情继续渐进披露，不应成为第一屏主叙事。
- 中英文 README 分文件维护并互相链接；两种语言结构和事实必须一致。
- 真实截图、原始日志与机器信息只进入本地证据区，不加入 Git。发布所需精选截图也先作为
  本地发布素材交付，遵守仓库隐私规则。
