# 工作范围

- 用户希望研究已经打开的 Autodesk Alias 如何获得 Glyphshift 文字支持。
- 目标是原位界面翻译；用户已授权继续实际测试，优先保证可用，必要时接受让用户重启目标软件。无需重启不是前置验收条件；不因追求晚附加而阻塞启动时接入方案。
- 尚未交付新的生产 Adapter。用户已明确当前 Alias 没有任何工程，授权后续直接验证、必要时重启；这一授权针对本轮空工程实例，不推广到未来含未保存工程的实例。
- Adapter 按文字技术组织，优先形成可复用的 Qt Quick 能力，不按 Alias 品牌硬编码业务逻辑。
- 现有 Qt Painter Adapter 支持动态 Qt 5/6 的部分 QPainter 绘制入口；QML scene graph 不自动包含在支持范围。
- 最小范围为非编辑标签、菜单与提示文字。模型名称、文件路径、表达式、数值和用户编辑输入不纳入首个写回原型。
- 归档 UIA 与依赖其的 OCR 不参与；本机原始证据仅保留在本地忽略目录，文档只保存可移植结论。

- 用户已要求把适配器放入 App 后自行验收，暂停自动逐项实机测试；必要的同步构建和生产 Loader 校验仍应完成。
