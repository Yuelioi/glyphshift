# 只读本地化查询：原生探针与实机对应

## 已完成

用户授权实施只读探针。本轮已完成独立原生宿主验证及一次新建设置界面的有效观测；未修改本地化表、函数参数、返回文字或设置，未重启目标，未新增产品 Adapter 或提交。

探针入口见 [实现与限制](../../../../test-support/vgui-localize-probe/README.md)，验证命令为 `scripts/test-localize-query-probe.ps1`。它使用既有 Frida 工具，不经 Glyphshift Runtime 加载器安装，不更新或替换驻留 Runtime；不是绕过版本保护的 Runtime 升级方案。

## 调用契约与独立验证

- 在既有只读入口调查基础上，重新取得当前对象和方法地址；三个选定方法的可达返回路径均核对为 x86 参数栈清理一致，结合此前查询链判断其名称/索引语义。样本配置和方法字节仅存本地，没有写入通用脚本的默认槽位。
- 探针限定 x86 thiscall，检查实际对象、方法地址、所属模块、可执行内存及预先核验的方法字节。所有检查完成才安装观察；没有主动调用表方法来试探参数。
- MSVC 独立宿主实际附加通过：名称和索引取词都观察到完整文本；原返回文字与 LastError 保持；卸下后不再产生观察且原调用正常。方法字节不匹配的负例在附加前拒绝。
- 这是原生观测工具的合同及特定目标入口核对，不是任意 Localize005 的通用自动识别。接口版本名本身仍不足以认证 ABI。

## 实机证据

先观察主菜单基线；首轮界面操作没有落入观测时段，不能拿它证明新建控件。随后改为同一自动化脚本等待探针就绪，再打开设置页，观测窗口固定为 20 秒，并为界面操作标记阶段。

有效一轮共有 117 种阶段/来源记录：基线名称查询 1 种，新界面阶段名称查询 64 种、按索引取值 52 种；读取拒绝为零。并非 117 个可见标签，记录中包含不同路径、格式串和未必显示的文本。

截图中预先确认的 **9 个设置标签**，均能在新界面阶段的记录里找到完全一致的完整文本；其中 8 个同时具有名称与索引路径记录。对应关系由本地字符串断言核对，页面文字由截图人工检查，未使用归档 UIA/OCR。

这证明该上层入口确实能提供新建设置界面所需的完整文字，值得进入写回验证。它还没有证明某一次查询就是最终绘制的唯一来源，也没有证明修改该返回值必定改变画面；后者需要受控替换验收。

观测结束后已停止、卸载脚本并断开会话，随后取消设置页回到主菜单，目标正常响应。未改变设置或原始文本。
