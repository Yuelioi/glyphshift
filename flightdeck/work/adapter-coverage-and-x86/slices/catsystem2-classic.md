# CatSystem2 经典字符串分支

Status: Experimental

## 问题与实现

经典对象的 RTTI、虚表长度、调用约定、编码、颜色前缀及结束标记均不同于现有 UTF-8 分支。原识别器拒绝该形态，因此系统菜单能被 Windows 适配器处理，但正文未进入 CatSystem2 对象链路。

新增经典结构 profile，关联 RTTI、命令表、复制与销毁、显示与完成状态；不按游戏名、固定地址或正文选择目标。通过可执行调用桥适配寄存器参数，复用原有对象归属、外部追加前恢复、字典换代和停止恢复。目标自身 setter 复制正文，随后在对象线程提交显示及完成指令，不推进剧情。

经典文本按目标系统 ANSI 代码页严格往返转换，保留已识别的前置颜色命令和末尾标记。无法表示的译文保持原文。未知标记、其他 ABI、其他引擎版本、混合分支、经典历史页和字体回退未验收。保留既有逻辑 ID 与实验标记。

## 证据

- 原识别器对授权运行时映像拒绝；新增识别器得到唯一结构候选。
- setter 单独写入实验：原始缓冲接受新值但画面为空，不能据此判定翻译成功。
- 补齐显示与完成调用后，实验画面恢复原文；修正控制前缀边界后首字符乱码消失。
- 实际原生 DLL 与本地 Native Host 在授权目标上完成英文替换、中文次代替换、停止恢复；缓冲断言和三阶段画面均通过，无重启、无推进剧情。此证据尚不是 App 探针端到端验收。
- `scripts/test-catsystem2.ps1`：5 项单元通过；9 个宿主变体通过，包括两分支各两种布局及 5 个错误形态拒绝。覆盖刷新、相同译文重试、恢复、追加、外部改字、重入、资源上限和超时；经典历史页没有列入支持。
- 严格 x86 Clippy 通过；Release DLL 的两分支各两种布局合同通过。
- CatSystem2 catalog Playwright 1 项通过。`scripts/review-app.ps1` 同步构建并启动 Release App，生产加载器校验 13 项通过。

实机实验工件与回调驻留至目标退出，已停止并恢复原文；切换后续 App 工件前需由用户正常重启目标，避免同时使用两套原生 hook。所有原始证据留在本地测试目录。

## 后续验收

使用同次构建的 App/Runtime Bundle，在干净目标进程验证探针收集、字典编辑、即时刷新和停止恢复。经典分支继续实验，扩展其他作品及代码页前需独立样本证明；不从本次结果推广至所有 CatSystem2 游戏。
