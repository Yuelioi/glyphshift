# 研究范围

- 用户询问星露谷中文字体是否依赖固定预设，要求核查适配器遗漏，并把 x86 支持作为下一目标。
- 已验收的 Qt 修复已提交；用户在比较研究后授权实施 x86。首批交付 GDI 双架构链路，真实软件覆盖仍须单独验收。
- 优先保持通用 Adapter 技术入口，区分机器配置、文字内容、字体候选及框架特定实现。
- x86 指支持 Windows 32 位目标软件；先评估保留现有 x64 App 并连接 x86 目标，而不是默认将整个桌面 App 改成 32 位。
- 不运行归档 UIA/OCR，不使用 workspace 范围原始 Cargo 命令；本机原始证据留在 local-test。
- 用户认可一个逻辑适配器支持多架构工件，不希望界面拆成 x86/x64 两个适配器或要求手动选择位数。架构匹配是加载职责。
- 用户要求先认真研究成熟软件的实际做法；实现选择复用现有 Controller 的双编译，不新增助手角色。
- 同位数执行组件是候选方案，不是操作系统规定必须存在的独立常驻助手。优先比较复用现有 Controller 的双编译与其他连接实现，避免新增重复角色。
