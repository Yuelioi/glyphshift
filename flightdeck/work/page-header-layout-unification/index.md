# 一级页面页头与内容轴统一

Status: Finished

## Goal

让桌面应用的所有一级页面共享正式、稳定的满宽布局：统一图标页头和左右边界，移除设置与帮助的独立
窄内容轴，并让标题栏版本自动跟随发布版本。

## Current

标题栏现在从桌面 package 元数据读取并显示完整版本。所有一级页面共享图标页头和 16px 页面 inset；
设置与帮助已移除 980px 居中内容轴、额外页面级水平 padding 和双边滚动留白。共享表单分区也改为
占满其容器，独立详情页头保持原有返回、状态和动作语义。帮助页头的重复说明已从中英文界面删除。
