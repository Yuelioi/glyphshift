# 探针与词典创建流程收敛

Status: Complete

## Outcome

新建探针任务与新建词典在每次打开时都从干净表单开始，取消或关闭不会把未提交内容带到下一次
创建。任务名称与新词典名称始终由用户填写，不根据所选软件自动生成；创建阶段只询问完成当前任务
所需的信息，词典的发布类元数据继续在词典设置中维护。

## Delivery

- [x] 新建探针任务在打开前统一重置任务名称、软件、Adapter、实时预览、词典模式与语言；任务名称
  与新词典名称保持为空，不从软件名称推导。
- [x] 探针内创建空词典只显示名称、源语言和目标语言；内部 ID 自动生成，说明使用空默认值。
- [x] 独立新建词典只显示名称、源语言和目标语言；版本默认 `0.1.0`，其余便携元数据使用空默认值。
- [x] 取消、关闭和创建成功共用同一重置路径，避免隐藏的旧草稿跨会话残留。
- [x] 保留词典设置对说明、版本、作者、许可证、主页与标签的完整编辑能力。
- [x] “使用已有词典 / 新建空词典”使用主色选中态与 `aria-pressed` 明确表达当前模式。
- [x] Adapter 选择列表不再产生独立滚动区；紧凑窗口只保留 Modal 主内容的一条滚动路径。
- [x] 目标软件未启动时仍保存新任务并返回“待连接”；用户之后明确重连时继续返回具体的软件未启动
  错误，不把连接失败误报成创建失败。

## Evidence

- 桌面 Playwright 新增两个回归合同，覆盖任务名称、Adapter 选择、词典名称与语言的取消后重置，
  并确认创建界面不再出现内部标识或发布类元数据；紧凑窗口同时验证明确选中态与单滚动区。
- 桌面端完整 Playwright 回归 53/53 通过；创建流程视觉用例 2/2 通过。
- 桌面后端 39/39 通过，其中离线目标合同同时验证任务已持久化、状态为 Ready 且显式重连仍保留
  `runtime.target_not_found`；Vue 类型检查与生产构建通过，界面机械规则检查未发现问题。
