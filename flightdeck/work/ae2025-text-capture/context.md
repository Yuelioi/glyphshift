# 稳定上下文

- 用户在研究结论后继续要求解决方案；优先修复现有 DirectWrite Adapter 的文字采集，不新增私有 Adobe Adapter。随后明确要求使用修复版 Adapter 并打开桌面应用试用；使用原用户数据启动同源审阅版，试用后明确授权发布 0.4.1（commit、tag、push、Release）。
- AE 2020/2022 的既有排查包括短暂观测队列竞争和持续重绘 checkpoint 饥饿；两者均已有修复，不应未复现便认定 AE 2025 是相同问题。
- 官方界面改版声明、目标加载模块、实际文字入口命中分别是不同证据层级；模块存在不证明绘制经过该入口。
- 不启用、构建或测试归档 UIA/OCR。真实目标实验与原始证据只进入本机忽略目录。
- 若需构建或启动最新 Glyphshift 桌面审阅，统一使用 `scripts/review-app.ps1`。
- 实测版本是 AE 24.6.2 与 25.1；主面板的文字路径分别是 GDI+ 与 DirectWrite/Direct2D。结论不能直接外推所有版本或全部软件表面。
- 采集编译会同时请求观察与替换；修复前 DirectWrite 在观察回调之前检查替换资格，非空 Typography 导致提前返回。当前先发布实际绘制的原文，只有准备应用译文时才进行替换资格检查。
- 恢复采集与等价排版的中文替换分别验收。全文统一 Typography 可通过复制当前布局属性显示译文；局部样式、inline object 和 drawing effect 继续原样透传。
- 目标可在创建布局后更改格式和尺寸；替换必须以实际绘制时的目标布局为准，不能只保留创建时传入的 TextFormat。译文范围使用新的 UTF-16 长度，并保持原目标对象不变。
- 不扩大不支持布局的替换作用域，避免尚未采用的译文决策抑制下层绘制能力。没有新增 ABI、Catalog 能力或 AE 品牌分支。
- 创建空布局也必须更新布局身份：成功创建但没有可捕获原文时，清除复用地址的旧记录。不能把空文字当成“无需更新关联”，否则会将历史译文画进空白控件。
