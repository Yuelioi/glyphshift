# 本机实验知识提炼与清理上下文

## 本轮边界

- 用户要求整理可复用知识、清理 target，并使构建目录使用全局根变量加软件名；local-test 根目录也需收拢。
- 本轮保留最终验收、未完成调查、必要手写源码、工具依赖、视频工程及正在使用的配套 App/Runtime；清理可重建缓存与多余旧审阅版本。此前只保留源码的历史清理范围不适用于本轮新增证据。
- 共享全局 Cargo 根不属于单个项目，只能按本项目 package 清理。仓库内旧 target 是可再生成边界，不存唯一证据。
- local-test 的机器路径、PID、窗口信息、截图、转储和授权样本不得进入 tracked 文档。配置中不固定长期 PID，实际使用时重新获取。
- 历史脚本迁移后保留同组关系并更新显式路径；静态检查不代替实机复验。清理期间不触发历史目标或重新运行实验。

## 验收

- Cargo 路径隔离、子进程继承、重复解析和显式 override 有定向合同。
- 仓库旧 target 不存在；local-test 根只留入口与分类目录，未解调查和在用工件保留。
- 形成脱敏的已验证 Knowledge，未知问题留在 Work。
- 验证迁移脚本语法、配置加载、目录占用、Git ignore 和 tracked 隐私边界；不为清理重建全部缓存。
