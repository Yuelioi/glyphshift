# 本机实验知识提炼与清理上下文

## Boundaries

- `local-test/` 是被 Git 忽略的本机工作区，不是产品或测试的必需仓库资源。
- `target/` 是可再生成缓存边界，不能保留机器专属数据的唯一副本，本次工作结束前完整删除。
- 技术文档只记录可移植结论、必要命令、验证范围、失败边界与残余风险；不复制本机路径、用户名、
  PID、窗口标题、截图、原始日志、转储、授权样本或第三方软件内容。
- “复杂实验只保留源码”指只在 `local-test/` 保留继续复现所必需的手写源码、构建入口和简短本机
  README；依赖缓存、编译输出、运行时副本、抓取证据和可重新下载的上游源码均删除。
- 能由 tracked 正式实现、测试或文档完整解释的简单实验，在核对结论后整体删除。

## Acceptance

- 每个主要实验族都有明确的技术结论，并在适用时指向 tracked 权威来源；仅有本机材料的实验明确
  记录证据等级、适用边界或无独立沉淀价值，不在 tracked 文档列出本机源码与证据清单。
- 保留下来的复杂实验不含构建输出、运行证据或机器标识，并且不是 tracked 代码的必需依赖。
- `target/` 不存在；`local-test/` 的剩余内容符合最小源码原则。
- Git 状态只包含预期的脱敏 Markdown 文档，不包含 `local-test/` 或其他机器专属材料。
