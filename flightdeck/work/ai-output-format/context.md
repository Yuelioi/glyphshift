# 诊断边界

- 用户报告偶发 AI 任务错误，目标是定位原因，不能把合成格式案例冒充历史原始响应。
- 当前报错发生在 HTTP 成功且外层 JSON 中取到文本后，内层 `StructuredTranslations` 反序列化失败。
- 第三方 Responses 兼容服务不因请求中包含严格 schema 就免除客户端的结果验证。
- 重试沿用用户 Profile 的 maxRetries、取消令牌与既有退避，不重复已成功批次。
- 明确的 token 上限和拒绝需要不同处理，不作为一般偶发格式错误反复请求。
- 只采集通用合成词条，不记录授权头；真实响应保留于本机忽略证据区，跟踪文档仅保存脱敏结论。
