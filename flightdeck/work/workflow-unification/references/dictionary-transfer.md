# 字典导入与导出

## 职责

- 后端 `crates/product/desktop-backend/src/dictionary_transfer`：纯文本格式注册表，JSON、CSV、SRT 独立处理器。公共解析返回词条与可选字典信息；公共错误包含稳定原因码与行号、列号或条目位置。重复校验复用同一协调层。
- JSON 保留完整字典文档，CSV 只编码 source/translation；SRT 仅导入，不保存时间轴，因此不声明导出能力。
- 桌面 `probe_transfer`：限制文件大小和 UTF-8 输入，调用公共解析，映射前端错误；不再实现各格式解析器。字典文件导出仍使用原有原子写入，通过公共编码接口选择格式。
- 前端 `dictionaryTransfer.ts`：可用格式说明、所有文件预检、文件名错误汇总、导出调用。`dictionaryImport.ts`：独立的词条合并规则。弹窗只管理用户选择与字典创建，不识别文件内容。

## 扩展

新增格式时添加后端处理器并注册导入/导出能力，再补前端格式说明与错误文案。处理器不能创建字典或控制工作流。XML 需明确具体结构，不能仅凭扩展名将任意 XML 当作字典。

## 批量行为

所有文件预检通过才开始创建。分别创建允许统一语言和单独设置；JSON 的其他元数据保留。合并统一使用最终设置的语言，前/后文件优先只决定不同的非空译文，空译文不能覆盖非空译文。已有字典的覆盖模式继续允许主动清空译文，与文件之间的合并规则不同。

创建不是跨文件事务：成功项保留，同一弹窗的完成游标使重试跳过成功项，失败项设置仍可修改。取消或关闭弹窗不会删除已经创建的字典；重新打开是新一轮导入。
