# 构建缓存与本机实验的存放

构建产物按“全局 Cargo 根目录 / 软件名”隔离。Glyphshift 的 PowerShell 入口通过 `scripts/cargo-target.ps1` 解析根目录、附加 `glyphshift` 并将结果传给子进程；重复调用不重复附加目录，显式 override 保持精确路径。直接 Cargo 调用也先初始化该 helper。

本机测试根按用途分区：`tools/` 放复用工具，`software/<name>/` 放软件实验，`cache/` 放可重建缓存，`evidence/<topic>/` 放原始证据。根目录只保留导航、本机配置入口；软件路径集中到本机配置，PID 在每次运行时重新获取。

清理前先记录可移植结论、检查目录联接和运行进程引用。共享全局 target 只能按本项目 package 清理，不能整根删除；旧审阅 App 与 Runtime 必须作为一套处理，保留最新可用版本和仍被进程引用的工件。不会复现的问题与未确认假设留在 Work，不提升为 Knowledge。

移动手写脚本时同时迁移同组文件、更新相对路径并做静态检查；历史配置不能因为语法通过就宣称仍可用于当前目标。更新本地导航，禁止用根目录联接掩盖路径未迁移。
