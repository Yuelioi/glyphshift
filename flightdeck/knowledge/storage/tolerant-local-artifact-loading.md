# 本地 artifact 使用容错读取与严格写入

Glyphshift 的本机工作区按三个层级隔离持久数据错误：

- 字段：未知字段忽略；非法非核心字段恢复类型对应的安全默认值。
- 记录：缺少不可伪造身份或核心引用的记录只跳过自身，不拒绝同文件其他记录。
- 文件：JSON 语法损坏时保留原文件或 `.invalid` 副本，并继续加载其他 artifact。

容错只属于 store 的读取 interface。新建、编辑、导入、Provider 输出和运行时 wire 继续执行严格校验，
因此调用者不需要知道 JSON 恢复细节，也不能通过容错路径写入不满足领域不变量的新内容。

新增本地 artifact 时，至少提供未知字段、非法非核心字段、坏记录与坏文件四类读取合同；测试必须同时
证明其余合法内容仍可见，以及规范写回不重新输出未知或非法字段。
